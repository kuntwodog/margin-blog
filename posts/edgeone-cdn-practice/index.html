用 EdgeOne 给网站做国内加速

#CDN#EdgeOne#网络

站点托管在 GitHub Pages，国内访问速度不理想，于是接了腾讯云 EdgeOne 免费版做加速。

基本思路

  • DNS 用 DNSPod，把域名 CNAME 到 EdgeOne 分配的 eo.dnse2.com 地址
  • EdgeOne 里配置加速域名，源站指向 GitHub Pages
  • 申请免费证书，开启强制 HTTPS

这样访客走 EdgeOne 的国内节点，回源才走 GitHub Pages，速度从原来的秒级降到 0.1 秒左右。

几个坑

  1. 证书签发要等：申请免费证书后，边缘节点完全生效需要几分钟，期间可能返回默认证书，耐心等即可。
  2. 显性 URL 转发不支持 HTTPS：如果要接 CDN，源站记录要用 CNAME，别用 URL 转发。
  3. DNS 缓存：切换解析后，本地和运营商 DNS 可能还缓存着旧 IP，导致看到旧的错误页。手机切一次飞行模式通常就好了。

结果

配置完成后，htwok.cn 和 www 都走国内节点，HTTPS 稳定，速度令人满意。这类免费 CDN + 静态托管的组合，对个人站来说性价比很高。
