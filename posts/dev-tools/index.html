我常用的几个开发者工具

#工具#效率

分享几个日常开发中离不开的工具。

命令行

  • fzf：模糊搜索，配合 Ctrl+R 搜历史命令，效率翻倍
  • tmux：终端复用， SSH 断线也能保持会话
  • ripgrep：比 grep 快一个数量级的代码搜索

编辑器

VS Code 配几个趁手的插件就够了。主题用过很多，最后还是回到了极简的浅色主题——长时间看代码，护眼比花哨重要。

思考

工具的价值在于顺手，而不是多。与其收藏一百个效率工具，不如把三五个用到极致。定期清理工具链，保留真正常用的，反而更专注。

工具应该服务于思考，而不是成为思考的负担。
