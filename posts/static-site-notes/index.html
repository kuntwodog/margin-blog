用 Hugo 搭建静态博客的几点体会

#Hugo#静态站点#工具

最近把博客迁到了 Hugo，记录几点实际使用中的体会。

为什么选静态站点

动态博客（比如 WordPress、Typecho）功能强大，但需要服务器、数据库和持续维护。对个人博客来说，这些成本往往超过了收益。静态站点则相反：

  1. 快：纯 HTML，CDN 一分发，秒开
  2. 稳：没有后端进程，不会因为服务挂掉而 500
  3. 省：GitHub Pages、EdgeOne 等都有免费额度

Hugo 的一点使用技巧

Hugo 的速度确实名副其实，几百篇文章也是秒级构建。几个常用技巧：

# 本地预览
hugo server -D

# 构建生产版本
hugo --minify

模板方面，建议从极简开始，先把 baseof.html、list.html、single.html 三个基础模板写好，再逐步加功能。

关于主题

现成主题功能丰富，但也容易带来依赖和冗余。这次我选择自己写一套极简模板，CSS 变量做深浅色主题，无外部依赖，反而更可控。

适合自己的，才是最好的。
